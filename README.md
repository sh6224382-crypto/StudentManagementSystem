# Student Management System

A full-stack Student Management System built to manage student records through a simple and user-friendly web interface.

## 🚀 Live Demo

**[View Live Project](https://student-management-frontend-smoky-mu.vercel.app)**

## ✨ Features

- Add new student records.
- View all registered students.
- Update existing student information.
- Delete student records.
- Store and manage student data using MongoDB.

## 🛠️ Tech Stack

**Frontend**
- React.js
- JavaScript
- HTML5
- CSS3

**Backend**
- Node.js
- Express.js
- REST API

**Database**
- MongoDB Atlas

**Deployment**
- Vercel – Frontend
- Render – Backend

## 🌐 Deployment Links

- **Frontend:** https://student-management-frontend-smoky-mu.vercel.app
- **Backend:** https://student-management-api-n2k1.onrender.com

## 📂 Project Overview

This project demonstrates full-stack web development, REST API integration, database connectivity, and deployment using modern web technologies.
